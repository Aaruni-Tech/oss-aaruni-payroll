Aaruni Cloud developer quick start

These are interface examples. Check service availability and your account permissions before running workloads. Compute, Containers, and Render are administrator services.

CLI and SDK names

CLI: acloud. Node.js/TypeScript: @aarunicloud/sdk. Python: aarunicloud. Source and install instructions: Aaruni Cloud SDK repository.

Read gateway metadata

curl --fail https://api.aarunicloud.com/v1/status
curl --fail https://api.aarunicloud.com/v1/services

A responding gateway does not prove all services, workers, or storage backends are healthy.

Node.js

import { AaruniCloud } from '@aarunicloud/sdk';
const cloud = new AaruniCloud(); // ACLOUD_API_KEY from your environment
console.log(await cloud.services());

Python

from aarunicloud import Client
cloud = Client()
print(cloud.services())

Credentials

Keep API keys on your server or local machine. Do not commit them or embed administrator keys in a public web page. Use separate credentials for development and production.

Service access

Review the service catalog, open the console, or request access. Runtime execution, quotas, data locations, and support terms need confirmation.

🔑 Scoped API Key & acloud CLI

Every Cloud Voice feature in this console is also available via the official acloud CLI, Node.js SDK (@aarunicloud/sdk), and Python SDK (aarunicloud).

1. Install & Use acloud CLI

npm install -g https://aarunicloud.com/sdk/aarunicloud-sdk-1.0.0.tgz

# Authenticate once (stores key in ~/.acloud/credentials.json chmod 600)
acloud login --api-key YOUR_ACLOUD_KEY

# Clone your own voice & synthesize studio audio
acloud voice clone ./my-voice.wav --name "My Voice" --consent-code 4829
acloud voice list
acloud voice speak "Scale PostgreSQL and NGINX with kubectl" --voice vox_id

2. Python SDK (aarunicloud)

pip install https://aarunicloud.com/sdk/aarunicloud-1.0.0.tar.gz

import aarunicloud as acloud

client = acloud.Client()  # Reads ACLOUD_API_KEY or ~/.acloud/credentials.json
voices = client.voice.list()
res = client.voice.speak("Deploy PostgreSQL on Aaruni Cloud", voice_id="stock_aria")
print(res["normalizedText"])
